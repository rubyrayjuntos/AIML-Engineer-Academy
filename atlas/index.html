Who this is for

  • Software engineers moving toward LLM, RAG, and agent systems who keep hearing terms they have not placed.
  • ML practitioners who can train models but have not seen serving, eval gates, or indirect prompt injection.
  • Staff engineers and managers who review designs and need a shared vocabulary.
  • Study groups and internal enablement: read the map, run the CPU labs, then talk.

Who should skip it

  • Anyone shopping for a career replacement, a GPU bootcamp, or a vendor certificate.
  • Anyone who needs to ship production RAG, live fine-tunes, or GPU serving from this repo alone.
  • Anyone who wants the in-app certificate treated as a hiring credential. It is a local keepsake.

What is inside

Five modules, Python labs graded by pytest, and teaching simulators. Every topic is supposed to be one of three things: CPU-proved (you run it), survey (you can talk about it), or optional live (env-gated; CI leaves claims false).

M1 Foundations

SSE FastAPI, Docker, TF-IDF, leakage clinic, PII mask, CPU RAG cite.

M2 Architectures

NumPy KV/LoRA/MoE/GRPO/DPO/diffusion toys. FlashAttention, MLA, GQA, QLoRA train as survey or optional GPU.

M3 Agents

HITL ReAct, read-only SQL/MCP, Dual-LLM IPI topology. LangGraph and live Playwright optional or survey.

M4 Serving

Authenticated FastAPI, CPU latency budgets, speculative math. vLLM/PagedAttention survey or optional GPU.

M5 Production

Offline eval gates, canary reject, rollback, provider plans. DeepEval/OTel/Ragas survey or optional.

What not to expect

This does not make someone able to perform the job. It does not replace shipping systems, on-call, messy data, or stakeholders. Quizzes are multiple choice. Labs are small CPU artifacts. Optional GPU, Playwright, DeepEval, and cloud deploys are off unless you turn them on on hardware you control — and evidence files must not claim they ran if they did not.

    How to use it

    1. Read this atlas. Filter the sheet until the legend is clear.
    2. Run the applet for theory, quizzes, and simulators.
    3. In each lab venv, run pytest. That is the proved column — not the certificate modal.
    4. Treat optional tracks as extra, never as the default story.

    Open the applet This file was opened on its own. From the repo: npm run dev, then localhost:3000/atlas/ or localhost:3000 for the applet.

    Shared learning space. Not a paid product, not a hiring credential, not a complete apprenticeship. The map is the product; the labs are selected soundings.
